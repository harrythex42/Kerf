# 网页可行性测试：结论与限制

**目前可以继续做网页版原型，但还不能承诺所有浏览器都能「预览即所得」。** 本地网页已经能把 Markdown 变成可打印的 A4 预览；粘贴的内容不交给服务器。正式包没有改动，也没有发布、部署或推送。

## 怎么看结果

- 每份样例、每种字体的结果：[自动检查表](../../output/web-feasibility/report.md)。
- 每页 PDF 图片：[四列并排查看](../../output/web-feasibility/images.html)（系统字体 / 按需字体 / MCP 全局最优 / MCP 贪心）。
- 如何在 Safari、Firefox 和 Chrome 复查：[负责人手动清单](README.md#safari--firefox-手动清单各约-10-分钟)。

比较的是每页第一个块；如果一张表跨了几页，还比较每页的第一条数据是哪一行。预览与打印使用同一套已排好的页面；自动检查另外比较了屏幕和打印样式下块的尺寸、位置，PDF 的实际页数和逐页正文。核对文字时只忽略空白，**不会**把长得像但实际不同的汉字当成相同。搜索检查会在每页找一个实际存在的词，不代表逐个词都搜索过。

HTML 样例是网页的测试入口，不是公开的输入功能。其中外链样式先嵌入，两张外链 SVG 先转成内嵌 PNG；MCP 和网页使用同一份处理后的样例。正式验收仍读取原始 HTML。图片比较没有要求字体像素逐点完全相同，也没有覆盖所有屏幕尺寸。

## Chromium 测得什么

共 23 份文档（17 份原有 HTML、6 份新 Markdown），每份测 A 和 B。

| 字体 | 每页开头同 MCP | PDF 页数同网页 | 有空白页 | 文字与原文一致且可搜索 |
| --- | ---: | ---: | ---: | ---: |
| A · 系统 | 21 / 23 | 23 / 23 | 0 | 11 / 23 |
| B · 按需 | 23 / 23 | 23 / 23 | 0 | 23 / 23 |

系统字体的两份分页差异都是长表。例如 Markdown 长表在 B 和 MCP 的第 2、3 页从班次 22、45 开始，A 从 23、47 开始。已安装的 Chrome 另做两份自动对照（Markdown 长表和带图文档），观察到同样的差异。

原字体约 10.1 MiB，切成 49 份压缩文件。三份典型中文文稿只下载 1–3 份，约 **553–731 KiB** 字体，加 **57 KiB** 字体样式。A 下载 **0 KiB** 字体，只取 **不到 1 KiB** 的样式。等待时间是本机、清空缓存后的测量，详见自动检查表，不代表真实网络。

项目原有的 `pnpm acceptance`：**34 项通过，0 项失败**（[正式验收报告](../../output/acceptance/report.md)）。测量脚本对 A 的差异返回非零，这是实验发现，不是正式验收失败。

## 需要注意

- **系统字体 A 不下载字体文件，但中文可能复制错。** 例如「人」可能变成形似的「⼈」；表格也可能早一行或晚一行换页。同一份原稿在不同电脑上可用的系统字体未必相同。
- **按需字体 B 更值得优先验证。** 它从已有的改造字体切出压缩小块，不重新拿原版 Noto 切；构建会逐个校验字和原字形的对应关系、横向尺寸，并保留 OFL 许可证。代价是首开需要等待字体下载。
- **无法从网页强制浏览器的打印设置。** 已使用 A4、零外边距，正文自己的页边留白仍保留。自动打印里，强制打开 Chromium 页眉页脚仍能产生额外文字。因此不要承诺零边距在所有浏览器和所有用户设置下都能消掉日期、网址；手动清单明确要求关闭，选 A4、100%。
- **未完成 Chrome 手动保存。** 当前会话无法操作实际的 Chrome 打印对话框；已安装的 Chrome 也做了自动检查，但 Playwright 不经过用户看到的对话框，不能代替这项。Safari、Firefox 手动打印也尚未验证。

**下一步**：先请负责人按清单保存 Safari、Firefox 各三份 PDF，再补一份 Chrome 手动 PDF。若通过，建议将 B 作为正式原型的首选；如果首开下载太慢，再决定是否提供 A 作为明确标注「文字复制可能有差异」的备用选项。先不决定默认字体。

## Chrome 手动打印结果（11 月 24 日）

负责人在本机 Chrome 里用真实打印对话框存了 `web-02-table.md`、字体 B（`output/web-feasibility/manual/chrome-B-web-02-table-md.pdf`）：

- 3 页，A4，无空白页，无日期、网址；文字可搜索，复制与原文一致；表格无切开，续页重复表头。
- **打印和该标签页的预览一致**：预览第 2 页最后一行是 45，PDF 也是 45。
- **但和自动测试、MCP 不同**：它们把 45 放在第 3 页开头。两种排法第 2 页留白都在“免费留白”范围内（约 0.1% 与 4.1%），代价几乎相同，测量上极小的差别就会改变选择。用自动 Chrome 换窗口大小、屏幕倍率（1–3）、先 A 后 B 的操作顺序，都没能重现，原因未确定。
- 决定：Safari、Firefox 暂不测；先只保证 Chrome。Edge 内核相同，未测。
