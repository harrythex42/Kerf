# 分寸分页评审台

在项目目录运行 `pnpm review`，然后在浏览器打开 <http://127.0.0.1:4173/>。输入名字开始评审。点击「左边好」「右边好」或「差不多」会保存并自动进入下一组。键盘 `1`、`2`、`3` 分别对应左边好、差不多、右边好。点击任一缩略图可以放大。下次输入同一个名字即可继续，页面顶部会显示已评组数。

只想试评时，在首页点「改做试评（40 组）」，或直接打开 <http://127.0.0.1:4173/?mode=pilot>。试评有 34 道原题和 6 道左右互换的重复题，题目用固定种子 `unsliced-pilot-v1` 从当前材料挑选。试评和全量进度各自保存，同一个名字可分别继续。试评还留出了报告、多图、中等长度表格、密集标题和混排各一份文档，之后可用来独立检验调参结果；在完成调参之前，建议不要用全量模式预先评这些留出文档。

如果本地还没有评审数据，先安装项目依赖和 PDF 验收依赖，然后准备数据：

```sh
pnpm install --frozen-lockfile
python3 -m pip install -r scripts/requirements.txt
pnpm exec playwright install chromium
pnpm review:prepare
pnpm review
```

可用 `UNSLICED_PYTHON` 指定装有 PDF 验收依赖的 Python。准备数据会读取 `samples/`，再用固定种子补足 30 份，覆盖报告、发票、长表格、多图、密集标题和混合资料。程序先按分页位置去重，再按逐页图片去重。版式只有一种的文档会跳过。每种保留的版式都有 PDF 和逐页 PNG，并经文字、表格及页面边界校验。

## 多人一起评

在同一台电脑上可以直接点「换评审人」。每位评审人使用不同名字，共用评审数据，但各自保留进度。左右位置会为每位评审人和每组分配一次，刷新或重启后该组两侧保持一致。默认只接受本机访问。要邀请同一可信局域网里的朋友评审，可在主机上以 `UNSLICED_REVIEW_HOST=0.0.0.0 pnpm review` 启动，然后将主机局域网 IP 和端口 4173 发给朋友。局域网模式用名字区分评审人，适合互相认识的参与者。

## 记录和备份

每次判断追加到 `output/review/votes.jsonl`，每行一条完整记录。内容包括评审人、时间、文档及归档路径、左右顺序、各自的参数、各页留白和代价、固定页代价、拆表代价、规则放宽次数、表格分段位置和选择。拆表代价记在相应的续页。记录里的数据集和文档 ID 可在 `output/review/datasets/` 中对应到原文件与渲染结果。需要备份时，保存整个 `output/review/`。

试评记录额外保存 `mode: "pilot"`、全量题目的编号 `originalPairId`，以及重复题对应的试评原题编号 `repeatOf`（原题为 `null`）。比较重复题时用 `chosenVariant` 核对是否选中同一版，不要直接比较左右。全量记录格式不变。

重新运行 `pnpm review:prepare` 会生成一套新材料，之前的记录和文档仍保留。停掉并重启评审台后才会载入新材料，同一评审人在新材料上从 0 开始。
